# 🎯 Presentación

Bienvenido a mi portafolio académico de la materia **Desarrollo de Aplicaciones Web**.

Este repositorio reúne las prácticas, proyectos, evidencias, documentación técnica y análisis realizados durante el curso. Cada proyecto integra conocimientos relacionados con el diseño, desarrollo e implementación de aplicaciones web bajo arquitecturas cliente-servidor, utilizando tecnologías actuales para la construcción de sistemas funcionales y seguros.

La finalidad de este portafolio es demostrar las competencias adquiridas en el desarrollo de software web, la documentación técnica de proyectos y la aplicación de metodologías de análisis y solución de problemas informáticos.

# 💡 Reflexión del Aprendizaje

A lo largo del desarrollo de los proyectos incluidos en este portafolio se enfrentaron diversos retos técnicos y académicos que contribuyeron al fortalecimiento de mis competencias profesionales dentro del área de desarrollo de software.

## ¿Qué aprendí?

- A diseñar e implementar aplicaciones web utilizando arquitecturas cliente-servidor.
- A desarrollar interfaces mediante HTML, CSS y JavaScript.
- A procesar información utilizando PHP como lenguaje de programación del lado del servidor.
- A conectar aplicaciones con bases de datos MySQL.
- A implementar validaciones tanto en Front-End como en Back-End.
- A utilizar Git y GitHub para el control de versiones de proyectos.
- A documentar proyectos de manera técnica y profesional.
- A comprender la importancia de la seguridad informática en aplicaciones web.

## ¿Qué fue difícil?

- Comprender la comunicación entre cliente, servidor y base de datos.
- Resolver errores de conexión entre PHP y MySQL.
- Implementar mecanismos de autenticación y validación de usuarios.
- Organizar correctamente la estructura de carpetas y archivos de cada proyecto.
- Depurar errores de programación durante el desarrollo.
- Aplicar buenas prácticas de documentación técnica.

## ¿Qué mejoraría?

- Implementar sistemas de seguridad más robustos utilizando tecnologías modernas.
- Mejorar el diseño visual y la experiencia de usuario de las interfaces.
- Optimizar la estructura del código para facilitar el mantenimiento.
- Incorporar frameworks modernos para agilizar el desarrollo.
- Aplicar patrones de diseño y arquitecturas más escalables.
- Realizar pruebas más exhaustivas antes de la liberación de cada proyecto.
- Integrar despliegues en servidores reales para acercar los proyectos a entornos productivos.
